# REQUISITOS FUNCIONAIS
- O sistema deve cadastrar os produtos da cantina.
- O sistema deve atualizar os produtos da cantina.
- O sistema deve cadastrar as vendas de produtos.
- O sistema deve atualizar as vendas de produtos.
- O sistema deve cadastrar os usuários do sistema.
- O sistema deve atualizar os usuários do sistema.
- O sistema deve gerenciar os relatórios de vendas.
- O sistema deve gerenciar a autenticação de usuários no sistema.
- O sistema deve gerenciar as notificações para produtos acabando.

# REQUISITOS NÃO-FUNCIONAIS
- O sistema deve possuir interface simples e intuitiva.
- O sistema deve possuir boa usabilidade para usuários iniciantes.
- O sistema deve ser compatível com dispositivos moveis.
- O sistema deve impedir acessos não autorizados.
- O sistema deve apresentar mensagens claras de erro e confirmação.
- O sistema deve possuir padronização visual em todas as telas.
- O sistema deve suportar múltiplos usuários simultaneamente.
- O sistema deve ser de fácil manutenção para futuros desenvolvedores.
- O sistema não deve deixar dois itens repetidos de produtos.

# REGRA DE NEGÓCIOS
- Para a cantina, o usuário precisa estar autenticado para acessar o sistema.
- O estoque do produto deve ser atualizado automaticamente após cada venda.
- O sistema deve validar valores de produtos para que não sejam negativos.
- O sistema não deve excluir produtos e nem clientes, apenas usar inativo caso necessário.
